# Identity system

Three parts, each with one owner and one source of truth.

1. The mark. The master is a vector file with documented construction. Everything else, including rendered, 3D, glass, and motion versions, is an application derived from it. `references/mark-and-applications.md` has the rules and the review questions for a proposed application.
2. Type. A named scale with roles. A new size or weight enters the system as a token before anyone uses it.
3. Gradients. Each gradient is a named set of stops with roles and motion rules. A brief quotes a gradient by name, never by hex values pasted from a render.

`references/type-and-gradient-tokens.md` has the token formats. Use them exactly so the factory can build from your spec.
