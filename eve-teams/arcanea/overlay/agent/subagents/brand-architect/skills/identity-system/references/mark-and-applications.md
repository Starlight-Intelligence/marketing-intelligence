# The mark and its applications

## The master

- One vector master per lockup, stored as SVG with its construction grid.
- Construction notes: the geometry it's built from, the ratios that must hold, the optical corrections made by hand.
- Clear space as a multiple of a named unit from the construction, never a pixel value.
- Minimum sizes for screen and print, below which the simplified mark takes over.
- Color variants: full color, single color, reversed. Each is a vector file.

## Applications

A rendered, extruded, glass, metallic, or animated logo is an application. It is allowed and often wanted. It is never the master, and it is never the source a new application is built from.

Review questions for a proposed application:

1. Does it trace back to the vector master without redrawing it?
2. Do the construction ratios survive the treatment, including at the angle it's shown?
3. Is clear space respected in the final frame?
4. Does it still read at its smallest planned size?
5. Is it recorded as an application, with the master it derives from named in its provenance?

A render that fails any of these is sent back. A render that passes is approved as an application and never replaces the master.

## Changing the master

Changing the mark means changing the vector file deliberately, with a version number and a note of what changed and why. A render someone liked is not a reason on its own.
