# Claim types that get missed

| Kind | Example of an implied claim | Why it slips through |
| --- | --- | --- |
| Relationship | "her brother's old sword" | The sentence is about the sword |
| Count | "the five founders" | A number reads as decoration |
| Order of events | "after the fall of the city" | Sequence is assumed, never stated |
| Title or rank | "the high warden" | Titles look like description |
| Capability | "she can walk between worlds" | Reads as flavor text |
| Visual fact | a scar, a color, a crest in an image brief | Lives in the image, not the copy |
| Place | "the eastern archive" | Sounds generic enough to be safe |
| Absence | "no one has returned from it" | A negative claim is still a claim |

For each one, the question is the same: which canon heading says so? When none does, the claim is absent.

## Findings format

| Claim as written | Status | Canon heading | Fix |
| --- | --- | --- | --- |
| quoted text from the piece | locked, absent, or contradicted | the heading, or none | what the writer should change |
