# Turnaround spec

| Item | Minimum |
| --- | --- |
| Views | front, three-quarter front, side, three-quarter back, back |
| Pose | A-pose for rigging, plus one character pose |
| Projection | orthographic for the turnaround views, same scale across views |
| Lighting | flat and even across views, so form reads from line and value |
| Height chart | the character against a human-scale reference and two cast members |
| Callouts | costume layers, closures, materials, and anything that moves in animation |
| Detail sheet | hands, face front and side, any prop at two angles |

The silhouette test runs again on the final front and side views. A design that passed as a thumbnail and fails here goes back to step one.
