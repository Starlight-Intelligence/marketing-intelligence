# Record format

One Markdown block per piece:

```text
## <creator> / <short title>

Link:        URL
Platform:    platform and format
Published:   date
Read on:     date you read the numbers
Metric:      the metric and its value as shown
Baseline:    value, and whether it's the creator's median or a peer set (name the set)
Multiple:    metric divided by baseline, one decimal
Mechanism:   the one reason it worked, specific to this piece
Transfers:   what Arcanea could use
Doesn't:     what depends on this creator and wouldn't carry over
```

A field you couldn't fill from the page says "not shown". It never holds an estimate.
