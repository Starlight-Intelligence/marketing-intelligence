# Brief template

```text
Subject         what is in the frame, and the canon heading for anything canon-bearing
Use             placement, format, aspect ratio, final pixel size
Composition     focal point, read order, rule of the frame (thirds, center, diagonal)
Camera          lens (mm), height, angle, depth of field
Lighting        key, fill, rim; color temperature; the one logic the frame follows
Materials       per surface: roughness, metal, transmission, thickness
Surface         liquid-glass treatment per references/liquid-glass.md, or none
Gradient        gradient.<name>, which stops are visible, motion rule, still frame
Type            type.<role> tokens and placement, or none
Render target   anime key art, Unreal real-time, or Octane path traced; sampling notes
Must not show   anything that would break canon, the mark, or the gate
Provenance      tool, model and version, prompt, negative prompt, seed, reference files
```
