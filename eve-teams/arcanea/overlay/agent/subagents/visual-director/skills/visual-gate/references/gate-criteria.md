# Gate criteria

Each criterion scores 0 (absent or wrong), 1 (present but weak), 2 (solid), or 3 (exemplary).

| # | Criterion | 3 looks like |
| --- | --- | --- |
| 1 | Mark integrity | Any mark is a faithful application of the vector master, clear space held |
| 2 | Palette fidelity | Every color traces to a named gradient stop or brand token |
| 3 | Gradient motion | Stops move as the gradient spec says, and the still frame works on its own |
| 4 | Liquid-glass surface | Refraction, thickness, and edge light are physically plausible and consistent |
| 5 | Composition | One focal point, a clear read order, nothing competing at the edges |
| 6 | Silhouette and readability | Subject reads at thumbnail size and in a flat black fill |
| 7 | Light and material | One lighting logic across the frame; materials respond to it |
| 8 | Typography | Type uses the system's tokens, holds contrast, and sits in the composition |
| 9 | Canon fidelity | Everything shown is locked canon, or the frame shows nothing canon-bearing |
| 10 | Provenance | A complete `.vis.provenance.json` sidecar sits beside the file |

Scoring a brief instead of an image: score what the brief specifies. A criterion the brief leaves open scores 1 at most, since the render will decide it by accident.
