# Structured data and entity integrity

Read deployed HTML or verified source file, associated route data and factual entity registry. List detected `application/ld+json` blocks, actual page types and eligible content. Review IDs, URLs, publisher, author, canonical identity, offers, dates, breadcrumbs and relationships.

Propose only schema that matches **visible page content and actual site facts**; never invent product ratings, testimonials, organization registration details, review counts, prices, rankings or FAQs. Validate JSON syntax and apply current Schema.org and Google Search Central guidance for eligible rich results. `llms.txt` is not an eligibility requirement.

Return minimal JSON-LD diff, evidence for every nontrivial field, test plan against deployed render and whether snippet eligibility is documented or unverified. A valid JSON-LD object does not guarantee an enhanced result or AI citation.

**Do not publish** without file-specific approval and a checked PR.
