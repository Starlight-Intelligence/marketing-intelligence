# SERP competitive analysis

Specify query, location, language, device and observation time. Semrush `keyword_research.phrase_organic` with `positions_type: organic` provides normalized organic ranking URLs where supported; discover schema before execution. If inspecting search manually, describe the sampling method rather than invent positions.

Deduplicate URLs when the same page appears in multiple SERP features. Keep classic organic, paid placements, snippets, AI Overviews and local packs in **separate result sets**. Never map undocumented numeric SERP feature codes to human names.

Review the top relevant pages for content form, first-party proof, freshness where actually evidenced, product relevance, linking architecture and differentiation. Identify what the user can produce that is substantively better and less interchangeable, without copying competitors.

Deliver SERP evidence, a reasoned winner hypothesis, a ranked intervention and follow-up observation design. Explain when winning requires an authority asset or product utility rather than another article.
